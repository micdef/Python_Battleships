# Battleships

Bataille navale jouable en console, écrite en Python.

Projet de montée en compétence sur la programmation orientée objet en Python,
réalisé par un développeur .NET / C# : conception par classes, contrats vérifiés
à chaque couche, opérations « tout ou rien ».
